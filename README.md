# moalakat | المعلقات

مشروع تعليمي عربي تفاعلي لشرح المعلقات بيتًا بيتًا، مع عناية خاصة بـ:

- المعنى والمفردات
- إعادة تركيب الجملة نثرًا
- النحو والإعراب حين يكشفان المعنى
- علم المعاني والتقديم والتأخير
- البيان والصورة الشعرية
- الثقافة العربية والسياق الأدبي
- التفريق بين **نص الشاعر** و**قول الشارح القديم** و**التحليل الحديث**

## الحالة الحالية

تم بناء الجزء الأول من معلقة امرئ القيس: **الأبيات 1–6**.

## طريقة العمل

الموقع نفسه هو النسخة الأساسية القابلة للتطوير. كلما ننجز مجموعة أبيات جديدة، نضيفها إلى `data.js` مع الحفاظ على نفس البنية التعليمية.

الواجهة مصممة من الأصل للعربية RTL، وبها أقسام قابلة للفتح والغلق، وتحكم في حجم الخط، ووضع ليلي، وزر طباعة/حفظ PDF.

## الملفات

- `index.html` — هيكل الموقع
- `styles.css` — نظام التصميم العربي RTL
- `data.js` — المحتوى التعليمي
- `app.js` — بناء البطاقات والتفاعل
- `content/01-06.md` — نسخة نصية مرجعية للجزء الأول
- `SOURCES.md` — المصادر والمنهج

## المصادر الأساسية

- الزوزني — *شرح المعلقات السبع*
- ابن الأنباري — *شرح القصائد السبع الطوال الجاهليات*
- الخطيب التبريزي — *شرح القصائد العشر*
- كتب اللغة والمعاجم عند الحاجة

> ملاحظة منهجية: إذا اختلف الشراح في تركيب أو معنى، يُعرض الخلاف ولا يُقدَّم أحد الوجوه على أنه يقين إلا بقرينة.

## النشر

المشروع Static HTML/CSS/JS، لذلك هو جاهز للنشر على GitHub Pages أو أي استضافة static لاحقًا.
