# moalakat | المعلقات السبع

مشروع تعليمي عربي تفاعلي مخصص **للمعلقات السبع كلها**، وليس لمعلقة واحدة.

## بنية المشروع

الصفحة الرئيسية تعرض المعلقات السبع، ولكل معلقة صفحة ومحتوى مستقلان داخل المشروع.

### المعلقات

1. **امرؤ القيس** — قيد الدراسة الآن، والأبيات ١–٦ منجزة.
2. طرفة بن العبد
3. زهير بن أبي سلمى
4. لبيد بن ربيعة
5. عمرو بن كلثوم
6. عنترة بن شداد
7. الحارث بن حلزة

> عند وجود اختلاف في عدّ «المعلقات السبع» أو روايات النصوص نعتمد النسخة التي نقررها صراحة داخل كل معلقة، ولا نخفي الخلاف.

## نظام الدراسة

لكل بيت طبقات قابلة للفتح والغلق:

- المفردات
- إعادة ترتيب الجملة نثرًا
- النحو والإعراب حين يكشفان المعنى
- علم المعاني والتقديم والتأخير
- البيان والصورة الشعرية
- الثقافة والسياق الأدبي
- أقوال الشراح والخلاف بينهم

## البنية الحالية

- `index.html` — المكتبة الرئيسية للمعلقات السبع
- `poems/imru-al-qays/index.html` — صفحة معلقة امرئ القيس
- `data/imru-al-qays.js` — بيانات شرح معلقة امرئ القيس
- `content/imru-al-qays/01-06.md` — المرجع النصي للأبيات ١–٦
- `styles.css` — نظام التصميم العربي المشترك
- `app.js` — التفاعل وعرض بطاقات الأبيات
- `SOURCES.md` — منهج المصادر

## المصادر الأساسية

- الزوزني — *شرح المعلقات السبع*
- ابن الأنباري — *شرح القصائد السبع الطوال الجاهليات*
- الخطيب التبريزي — *شرح القصائد العشر*
- كتب اللغة والمعاجم عند الحاجة

## مبدأ تحريري

نفرّق بوضوح بين:
1. نص الشاعر.
2. قول الشارح القديم.
3. التحليل اللغوي/البلاغي.
4. السياق الثقافي.

المشروع Static HTML/CSS/JS وجاهز للنشر كصفحة ويب.
